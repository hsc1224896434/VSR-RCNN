# Code availability statement

The VSR R-CNN source code, reference configuration, training and evaluation
entry points, prior construction utilities, and an RSM implementation of
Eqs. (9)–(10) are available at
<https://github.com/hsc1224896434/VSR-RCNN>. The confidential inspection
images, annotations, and trained weights are not distributed.

The repository uses Apache License 2.0; see [LICENSE](LICENSE) and
